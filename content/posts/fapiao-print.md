每次报销季，财务群里都是一片哀嚎。从税务平台一张张下载电子发票、改名、整理，再打开 PDF 一张张打印——几十张发票搞下来，一上午就没了。更烦的是 OFD 格式，很多工具根本不认，印章还经常打歪。

后来发现了一个开源工具 [**发票酱**](https://github.com/erma0/fapiao-print)（⭐106），这些问题一次性全解决了。

项目地址：https://github.com/erma0/fapiao-print

## 🎯 这是啥

发票酱（TicketChan）是一个专为批量打印电子发票设计的轻量桌面应用，Rust + Tauri 2 构建，单文件 exe 即开即用。支持 PDF、OFD、XML 数电票、图片等多格式导入，拖入即识别发票信息，智能排版后一键打印或导出。还提供轻量版和 OCR 版两个版本，满足不同场景。

## ✅ 核心功能盘点

### OFD 完整支持

OFD 是国家标准电子发票格式，很多打印工具对它是"看得到打不好"。发票酱提供原生完整支持——矢量渲染、发票信息直提、印章保真，拖入即用，不需要 OCR。税务原版 OFD、iloveofd 转换、dzcp 公共服务平台等不同来源的 OFD 都做了适配，遇到解析问题还能反馈给作者持续修复。

### 多格式批量导入

支持 PDF、OFD、XML 数电票、JPG、PNG、BMP、WebP、TIFF。XML 数电票（v2.0.7 起）能解析 `<EInvoice>` 格式，直接提取发票号码、日期、金额、买卖方信息，汇总表、CSV 导出、批量重命名全兼容。

### 发票信息自动识别

文字型 PDF 通过文字层坐标提取，约 5ms/页，无需 OCR；图片型 PDF 和图片则交给 PP-OCRv5 智能识别，含税价/不含税价/税额数学验证配对，发票号码、日期、买卖方信息自动提取。识别失败时金额卡片会亮 ⚠ 警告标识，hover 查看验证详情，避免报销出错。

### 智能排版不费手

纸张支持 A4/A5/B5/Letter/Legal/自定义；布局 6 种预设（1×1、2×1、3×2、1×2、2×2、3×3）+ 自定义行列（1-10 × 1-10），自动横纵方向；边距间距独立可调；支持全局旋转和单张旋转。

最实用的是**单票独立调整**：每张发票预览拖拽移动 + 角落 handle 缩放，九宫格快速对齐，滚轮微调（5%/步），±150mm 偏移范围，双击重置，参数还能持久化记忆。

### 四种打印模式

- **PDF 阅读器**（默认）：生成 PDF 后交给系统默认程序，矢量质量，数据量最小
- **弹窗确认**：预览后确认，可选 PDFium 或 SumatraPDF 引擎
- **静默打印（PDFium）**：Chromium PDFium 直打打印机 DC，打印清晰，无需人工点确认
- **静默打印（SumatraPDF）**：通过 SumatraPDF 直接发送到打印机

份数控制支持全局 + 单张份数，逐份/逐页打印，双面，彩色/灰度/黑白。打印前还有确认弹窗显示发票数量、版面、纸张、打印机、引擎、份数，防误操作。

### 报销一条龙

- **批量重命名**：预设模板（金额+销售方+号码等）或自定义字段，一键重命名发票磁盘文件，重名自动加序号
- **发票汇总表**：一键导出所有发票明细，14 个字段可勾选，金额可编辑修正，合计行自动汇总含税/不含税/税额，CSV 格式 Excel 直接打开
- **发票查验**：一键跳转国家税务总局查验平台
- **打印状态追踪**：全部/未打印/已打印三种过滤，打印后自动标记绿色 ✓

### 细节体验

深色/浅色模式、骨架屏渐进加载（大文件不卡 UI）、EXIF 方向自动修正（车票照片不歪）、PDF 双渲染引擎（WinRT 优先，自动 fallback PDFium，兼容企业精简版/LTSC）、PDF 印章烘焙（输出时印章位置大小与原票一致）、快捷键齐全（Ctrl+O 添加、Ctrl+P 打印、Ctrl++/- 缩放、Ctrl+0 自适应、←→ 翻页）。

## 🌐 还有 Web 版

纯前端零后端零构建，浏览器即开即用，和桌面版同一套代码核心。在线试用：https://fapiao.erma0.cn

适合公司内网部署：源码在 `web` 分支，可部署到任意静态托管（Vercel/Netlify/Cloudflare Pages/GitHub Pages/内网 nginx）。不过 Web 版受浏览器限制：无静默打印、无批量重命名、无 OCR、只能系统默认打印机，重度用户还是建议用桌面版。

## ⚠️ 注意事项

- **仅支持 Windows 10 1803+ / Windows 11**，不支持 Win7/8（依赖 WebView2 和系统 PDF 组件已停止支持）
- 文字型 PDF/OFD 选轻量版就够了；图片型 PDF 和图片需要 OCR 版
- 报"找不到 WebView2"就装一下微软 Evergreen 引导程序（约 2MB），装完重启应用
- 静默打印 PDFium 模式需下载 pdfium.dll；SumatraPDF 模式需安装 SumatraPDF
