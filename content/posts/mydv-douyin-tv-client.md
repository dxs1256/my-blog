躺沙发上想刷抖音，手机举着不到十分钟手就酸了；投屏到电视又只能看不能划，来回切 App 烦得很。可电视端一直没有官方抖音，用浏览器开网页版，遥控器操作稀烂，基本没法用。

直到我刷到 **myDV**（GitHub 1.2k Star）——一个开源的 Android TV 抖音客户端，装上之后遥控器上下左右就能刷大屏抖音。作者在 README 里写得很直白，连项目名都是"my Debug Video"：这是 AI 写的代码，"也不知道它都抄了谁的代码，在此一并感谢"。

项目地址：https://github.com/mytv-android/myDV

## 🎯 这是什么

一句话：**把抖音搬上电视的 Android TV 客户端**。APK 直接在 GitHub Release 下载，要求 Android 6.0 及以上，最新稳定版 V1.5.29（2026-09-27 发布），安装包 15.6MB。

![myDV 官方横幅图](https://i.ibb.co/BVZHQCgB/807c1e33c262.png)

它不是官方应用，也没上架应用商店，是社区开发者做的第三方客户端——需要联网登录你的抖音账号才能刷。登录方式不是输手机号验证码，而是填 Cookie，这点后面细说。

## 🔧 安装两步走

第一步，右侧 Releases 页下载最新 APK：

![GitHub Release 下载页](https://i.ibb.co/VYsFLvm5/3292785bfa8f.png)

第二步，安装到电视/盒子，有两种方式：

- **直接装**：把 APK 拷到设备上安装，电视/盒子需要允许"未知来源"
- **用姊妹项目安装**：官方推荐通过 mytv-android 来装，但这个安装工具本身也得先装好

踩坑预判：大多数电视盒子默认禁止安装未知来源应用，第一次装会弹拦截提示，去设置里开一下"允许安装未知应用"就行。

## 🍪 关键一步：填 Cookie

装好后要进设置填 Cookie，不然刷不了。这是整个流程里最容易被卡住的地方，细说步骤：

1. 电脑浏览器登录网页版抖音
2. 装一个 Cookie Editor 之类的浏览器插件（Chrome 商店直接搜）
3. 在插件里点 Export，选择 **Header String** 格式导出
4. 把导出的整串内容复制，贴进 myDV 设置的 Cookie 框

踩坑预判：不要在浏览器按 F12 用 `document.cookie` 复制——抖音的一些敏感 Cookie（尤其是和登录态相关的）通过这种方式拿不到，白忙一场。一定要用插件导出的完整 Cookie。

说人话：Cookie 就是你登录状态的"通行证"。App 拿着它去请求抖音接口，抖音就认你是已登录用户。

## 🎮 遥控器操作

装好填完 Cookie，就能躺着刷了。操作逻辑非常简单：

- 上下左右键移动焦点
- 返回键打开导航栏
- 视频页按左键/点屏幕左半部分：显示视频推荐面板
- 视频页按右键/点屏幕右半部分：显示进度条
- 继续按左/右键：快进/快退
- 确认键/点屏幕中间：暂停/播放
- 支持手势左右拖拽快进快退
- 连按两次返回键退出应用

![GitHub 仓库页](https://i.ibb.co/kgTbTHvm/33c57352ccce.png)

习惯手机下滑刷视频的人，第一次用方向键上下移动焦点要稍微适应一下，适应后反而轻松——手不用一直举着。

## ⚠️ 说点大实话

这个项目最大的特点不是功能多，是**坦诚**。README 封面就写着"卡是正常的，保持深呼吸"，作者还在卸载说明里写着：请在安装后 24 小时内卸载，"因为这个项目不是用来在 TV 上刷视频的，只是告诉你 AI 写的代码有多厉害"。

翻译一下这几点隐患：

- **会卡**：AI 写的代码，性能优化别期待太多，作者的预期就是"卡是正常的"
- **Cookie 会失效**：抖音登录 Cookie 过期或被风控后，可能要重新导出填写
- **账号安全靠自觉**：第三方客户端要交出自己的抖音 Cookie，介意的慎用

## 🔀 和其他 TV 客户端比一比

安卓 TV 客户端类文章我写过 Selene-TV（多源聚合观影）和 TVAPP（TV 应用收录），和 myDV 的定位完全不同：

| 方案 | 定位 | 登录方式 |
|---|---|---|
| **myDV**（本篇） | 专刷抖音短视频 | 网页端 Cookie |
| Selene-TV | 多源聚合影视点播 | 配置数据源 |
| TVAPP | TV 应用商店合集 | 无登录 |

一句话决策：想大屏刷抖音 → myDV；想看影视剧集 → Selene-TV；想给盒子装更多应用 → TVAPP。各有各的活。

## 💡 最后

这个项目最打动我的不是"TV 刷抖音"这个需求本身，而是它展示了 AI 写代码现在能到什么程度——一个能跑、能登录、能刷完整视频流的 Android TV 客户端，一个人用 AI 辅助就能做出来，还开源了。当玩具试试挺有意思；真要长期用，记得它 README 那句"卡是正常的"。
