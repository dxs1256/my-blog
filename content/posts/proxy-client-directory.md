换新手机、新电脑，或者想给软路由配个客户端，最头疼的不是没有选择，而是信息太散：iOS 上哪些是付费的、Linux 上哪款还在维护、某个客户端到底是不是开源，得挨个去 App Store 和 GitHub 翻，翻完还怕下到冒牌货。

后来朋友甩给我一个叫 **华润赢** 的网站，说是"翻墙应用商店"。打开一看确实像那么回事——一个收录了 137 款代理客户端的目录，Android、iOS、Windows、macOS、Linux、HarmonyOS、OpenWrt 全都有，还带筛选器和历史资料。想找什么客户端，不用再瞎逛了。

项目地址：https://huarun.win

## 🎯 这是什么

华润赢是一个面向代理客户端的"应用商店式"目录站，跟 FMHY 那种资源索引是一个思路：**只做信息整理，不托管任何东西**。它不提供节点、订阅、破解，也不镜像安装包，每条记录只链到官方仓库、官网或商店页面，相当于一个经过核对的客户端黄页。

覆盖规模直接看数据：全部 137 款，其中 Android 42 款、iOS 57 款、HarmonyOS 4 款、Windows 49 款、Mac 58 款、Linux 40 款、OpenWrt 12 款（一个应用跨多平台会重复计数）。主流的 Shadowrocket、FlClash、sing-box、Clash Verge Rev、v2rayNG、Stash、Surge、Quantumult X 全在列，小众的比如 Sudoku、KunBox、MonadBox 也有收录。

![华润赢首页，展示应用目录和筛选器](https://i.ibb.co/QvfXwdH8/10d608ea3dcd.png)

## 🔍 筛选器：四个维度缩小范围

这是目录站最实用的部分，每个维度都是踩过坑的人才知道要看的：

- **按平台**：Android / iOS / HarmonyOS / Windows / Mac / Linux / OpenWrt，软路由用户直接筛 OpenWrt
- **按内核**：Mihomo、sing-box、Xray、V2Ray、Clash 或其他——先定内核再看客户端，避免选到不匹配自己订阅格式的
- **按代码状态**：开源 / 源码不完整 / 未公开，在意安全性的可以先看开源
- **按价格**：免费 / 付费 / 待核实，注意"免费下载但授权未确认"的被单独标成待核实，不糊弄人

每个应用卡片都标注了内核、代码状态、价格和平台，一眼扫过去就知道要不要点进详情。

## 📚 翻墙纪：内核谱系、协议与人物

目录之外，这站还藏着一个"翻墙纪"栏目，分四块：纪事（产品时间线）、内核、协议、人物。适合想搞清楚来龙去脉的人。

**内核谱系**把 GoAgent、Shadowsocks、V2Ray、Xray、Clash、Mihomo、sing-box 之间的分叉和继承关系画成了一张谱系图，明确区分"直接 fork"和"兼容借鉴"——比如 Xray 是 V2Ray 的直接分支，而 Clash 只是兼容借鉴，不是 fork。这种血缘关系网上很少有人说清楚。

![内核谱系页，展示代理内核分叉与继承关系](https://i.ibb.co/jvWqtHhJ/0864fa2b2e0f.png)

**协议推荐**是另一个亮点：11 个常见协议组合按"抗识别、传输能力、客户端支持、使用维护"四个维度打分，比如日常直连首选 VLESS + Vision + REALITY（4.5/5），高延迟丢包看 Hysteria 2（4.5/5），还明确标注了每种方案的适用前提。评分是编辑判断，不是实测结论，但比论坛里各说各话清楚多了。

![协议推荐页，展示协议组合评分表](https://i.ibb.co/pB978kcm/a08fb03920a8.png)

**人物纪事**给 clowwindy、Dreamacro、Blankwonder 这些核心开发者写了传记式条目，记录 2023 年 Clash 系列删库、Shadowrocket 2015 年上架这类关键节点，每条都附来源链接，区分"可核验事实"和"推断"，态度挺严谨。

## 💡 使用技巧

用下来有几个值得注意的点：

1. **详情页有官方入口**：每个应用详情页都列出 App Store / 官网 / GitHub 仓库链接，下载永远走官方渠道，站内没有安装包
2. **Telegram 频道接收更新**：关注 @huarunying 频道，客户端出新版本会实时推送
3. **先筛内核再选客户端**：如果你订阅的是 sing-box 格式，直接筛 sing-box 内核，避免选了不兼容的客户端
4. **纠错入口**：发现信息不对可以从详情页进纠错表单，是个活目录

![FlClash 应用详情页，展示平台、内核、代码状态信息](https://i.ibb.co/TqwnpqsD/3002e105daa1.png)

## ⚠️ 注意事项

华润赢只做信息索引，本身不提供代理节点和订阅服务，节点还是要从可信渠道获取。另外它标注的"开源""免费"是按项目资料核验的状态，不代表永久有效——应用下架、删库这类事这站自己也在纪事里记了不少（2023 年 Clash 系列删库就是活例子）。目录再全，也只是帮你少走弯路，实际用起来还是得自己试。

## 🤔 适合谁

- **多设备用户**：手机、电脑、软路由各要一个客户端，一站查清平台兼容性
- **刚入坑的新手**：不知道 iOS 上哪些要付费、Linux 上有什么可选，筛选器比问人靠谱
- **爱研究协议的玩家**：内核谱系和协议评分表值得反复看

我自己的用法是：换设备时先来这筛一遍，选两三个候选再对比详情，省去了一下午的搜索时间。这种把分散信息集中整理还坚持标注来源的目录，多来几个不嫌多。
