上班路上喜欢听广播，但经常听到一半就到公司了；平时干活的时候也想听点新鲜的，不想翻来覆去总是歌单里那几首；偶尔听到一首好听的，还得赶紧翻出音乐 App 去识别是什么歌。这是 V2EX 上一位老哥（ddter）做的小玩意要解决的事——打开网页按一下，随机掉进世界上某个城市的电台，听听那里此刻在播什么。

项目地址：https://roamdial.com

## 它是什么：不是音乐播放器，是"推窗看世界"

**RoamDial**（直译"漫游电台"）不是又一个音乐播放器，也不承诺收录所有电台。它的核心体验只有一句话：**按下播放，看看会落在哪里**。你听到的，就是那个台此刻正在播的——可能是东京早高峰的电车广播，可能是里斯本咖啡店放的爵士，也可能是某个南美小城午间的新闻。

每个电台都是一扇通往某个地方的小窗：那里的语言、新闻、广告，还有当地人今早挑的歌。页面引用陶渊明的话做注脚："缘溪行，忘路之远近"——跟着声音走，忘记走了多远。

## 能做什么

按作者帖子里的说明，实用功能分三块：

**路上没听完 → 接着听**
- 每个台都有分享链接，到公司在电脑上打开接着听
- 同一浏览器下次打开，会停在上次听的台

**想听点新鲜的 → 随机换台**
- 按「下一站」随机换台，连续翻台时提前缓存后面几台，基本是秒切
- 可以只听高码率（≥128 / 192 / 320 kbps），也可以在设置里只留想听的语言

**听到好歌 → 识别 + 收藏**
- 能读到曲名的台，直接显示"在播什么歌"
- 读不到的，点「识别这首歌」就行
- 曲名旁点 ♡ 收藏，顺手跳去网易云、QQ 音乐、Spotify 搜
- 能读到曲名的台还能开歌词跟唱

## 星图玩法：按流派铺成一片星空

RoamDial 最有辨识度的是它的**星图**：几万个电台按流派铺成一片星空，可以拖着逛——想听爵士就往爵士的星群飘，想听古典就往另一边。也有地球视图，按地理位置钉电台。

设计哲学（About 页原话翻译）：
- **声音优先**——播放、下一站、收藏永远在手边，星图是来逛的，不挡路
- **真实**——只展示拿得到的信息：读不到频谱就不画假波形，只知道国家就不标城市，码率照电台自报的写
- **不轻易断**——一个台的一条线路不通，自动换下一条

## 技术栈与数据来源

- 前端 React + three.js（星图是几万个粒子），后端 Node + SQLite
- 电台目录来自社区维护的 **Radio Browser**，地理数据来自 GeoNames，声音直接来自各电台自己的服务器
- 目录每周自动刷新、探测哪些台能播

## 我的判断

这个工具适合两类人：**一是通勤路上想"换个世界听"的人**——随机跳到陌生城市的电台，比歌单多一分惊喜感；**二是喜欢当背景音干活的人**——电台不间断、不用管选歌，码率和语言筛选能保证听到的是自己想听的类型。

限制也很明确：**部分海外电台在国内网络下可能连不上或比较慢**（作者自己标注的已知问题）；iPhone 上的秒切效果还没实测。另外它依赖 Radio Browser 社区目录，收录的台偏"能在互联网公开收听的"，小众本地台可能没有。

不用装 App、没有账号、没有广告，收藏只存在浏览器里——打开就能用，这是它最讨喜的地方。想换个世界听听，打开这个页面按一下播放就行。
