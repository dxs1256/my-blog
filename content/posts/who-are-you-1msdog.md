我开代理有一个习惯：心里总觉得"换个节点、开个无痕，网站就认不出我了"。直到有一天刷到 1ms.dog 工具集里这个叫 **你是谁**（who.1ms.dog）的页面，它上来就是一句扎心的话：118 个探测项，不用你授权。点开一测，它用几段大白话把我整个环境描述了一遍，连"像是远程桌面、虚拟机，或者浏览器没开硬件加速"这种细节都猜出来了。

项目地址：https://who.1ms.dog/zh-cn/

## 🎯 它到底在测什么

这个页面做的事很简单：把网站不用你同意就能读到的信息全部读一遍，然后告诉你——在网站眼里，你是谁。浏览器指纹、IP、语言、时区、显卡、字体、WebRTC、DNS 服务器……一共 118 项，全部在本地检测完后拼成一段人话。

我实测这台 Linux + Chrome 155 的环境，它给出的画像大意是：

> 语言设置指向美国，人说美国英语，时区 GMT+00:00，12 小时制；用的是 Linux 电脑、Chrome 155、1280×720 屏幕，显卡是软件渲染——像是远程桌面、虚拟机，或者浏览器没开硬件加速。

![「你是谁」首页检测完成后生成的画像段落](https://i.ibb.co/PGpPqKv2/3d322ebb36d6.png)

注意"软件渲染"这个判断：我这边确实是云端虚拟桌面，显卡走的是 SwiftShader 软渲染，它一个探测项都没放过，直接反推出来了。这比大多数 IP 查询站输出的"您正在使用位于 xx 的 IP"有价值得多。

## 🕵️ 指纹 ID：换网站、无痕、开 VPN 都变不了

页面中间有一张浏览器指纹卡，它告诉你一个残酷的事实：浏览器指纹 ID 和 IP 无关，换网站、开无痕、开 VPN，它都不变。这串 ID 由 Canvas、WebGL、音频、字体、屏幕、显卡这些细节合成，网站之间可以通过它默默认出"这是同一台设备"。

它还理解了"指纹的稀有度"：每多 1 比特，和你一样的人就少一半。如果 118 个探测项全是常见值，那你的指纹可能模模糊糊；一旦带 4K 屏、独显、冷门字体这种罕见组合，基本就是人群里独一份。

![指纹识别卡：说明指纹 ID 与 IP 无关，且解释比特稀有度](https://i.ibb.co/s9MN4RWg/06034613e00e.png)

## 🎭 伪装检测：你最常露馅的地方

这是整个页面里最实用的一块。它把"你平时开着的代理/伪装"和真实环境逐项对照，标出哪些对不上：

- **分流**：走的代理只有一半流量，国内直连、国外走代理，网站一对照就发现你在用代理——过去 7 天 16.5 万次检测里，54% 的人在这项露馅
- **WebRTC**：代理客户端没开 TUN，真实局域网 IP 直接被 WebRTC 暴露
- **DNS 泄露**：DNS 请求没走代理，解析记录暴露了你的真实运营商
- **时区**：IP 在日本，系统时区却是 UTC+8，一对比就知道你不在日本
- **UA 与显卡**：UA 改成 Mac 但显卡是 NVIDIA 独显，改得不够彻底照样穿帮

![伪装检测与全部探测项列表：每项都标注读到的值和对应的 API 来源](https://i.ibb.co/LzykSHDb/c9834de36a24.png)

每一项后面都带"怎么改"的提示：TUN 模式、安全 DNS、改系统时区、用指纹浏览器，直接给方案，不用自己搜。这其实是一份现成的"防追踪补课清单"。

## 🔒 隐私本身也做得干净

检查隐私的工具如果自己记录数据，那就本末倒置了。它明确写了：不存 IP、不存完整指纹、不记日志，只有匿名计数；单次访问不留记录，分享链接也只带画像不带地址。代码在 GitHub 开源（星标 322），想确认数据流可以自己翻源码。

网站背后是 1ms.dog 一整个工具集：出口照妖镜（每个网站看到的出口 IP）、IP 质量、流媒体/AI 解锁检测、网速、DNS、IPv6、CDN、traceroute 全是同类质量，且都免费。对折腾代理、自建服务的人来说，这一组工具基本是常备工具箱。

![1ms.dog 工具集导航：网速、DNS、IPv6、CDN、出口照妖镜、解锁检测等全套检测入口](https://i.ibb.co/rfsgjKXq/a5138ceb5a83.png)

## 💡 我的判断

开代理不等于隐身，这句话我是在跑完这个页面后才真正有体感的。别的不说，就冲它能说出"你这行为像远程桌面"这一句，就值得所有玩代理的人点开测一次——看看自己平时到底漏了多少信息出去。测完重点看伪装检测那栏，有几项标黄标红，照着提示改，比盲调 Clash 配置高效得多。
