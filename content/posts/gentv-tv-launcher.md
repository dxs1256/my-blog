我家的电视一开机，先看 15 秒广告，进首页再撞一排「猜你喜欢」，想找个自己装的 App 得先穿过两层推荐位。电视是花钱买的，首页却像租来的。

后来发现了 **GenTV**（⭐89），它冲着这块首页来：一个免费开源、无广告的 Android TV / Google TV 桌面。最特别的是它不靠电脑、不 root、不要账号——装桌面、清预装、当遥控，全在一部安卓手机上完成。项目 2026 年 10 月底开源，MIT 协议，Java 写成，最新版 v3.7.14 就在今天（11-24）更新。

项目地址：https://github.com/Elaine-Lynn/GenTV

![GenTV 桌面与手机遥控器：大时钟加一排应用卡片，没有推荐位和赞助横幅](https://i.ibb.co/hjH0XJY/ff68099a364e.png)

## 🎯 一块真正「只是桌面」的桌面

GenTV 的首页没有推广、没有推荐流、没有会员角标，只有你的应用、壁纸和信号源，全做成适合遥控器操作的大卡片。Apple 风简洁桌面和互动养鱼桌面两套主题随便切，重启后还记得你选的那套。

跟很多「去广告工具」拆系统组件的路子不同，GenTV 是桌面层替换——它不动任何系统应用，你装的 App、账号、原厂桌面都还在，随时能切回去。

## 📱 手机就是遥控器加键盘

同一局域网配对后，手机端有方向键、触控板、键盘输入、文件传输四合一，还能直接编辑电视桌面——排序、改名、隐藏、分组、换卡片图，不用在电视上用遥控器一格格挪。用遥控器整理图标有多痛苦，用过都知道。

![手机端三屏：维护清理 / 遥控器 / 桌面编辑](https://i.ibb.co/Lz6dzx4K/beff83080656.png)

## 🧹 清预装应用，而且能还原

手机端能查存储、清缓存、逐个查看并停用或卸载预装 App；系统核心组件受保护，每一步改动都有记录，改错了可以一键恢复。它内置 252 款电视/盒子/投影机的社区清理清单（TCL 57、索尼 32、小米 29 等）。这只是一份「参考名单」，不是「保证能清」，动手前先看机型。

## 🚀 上手：从手机装起

先确认电视是 Android TV / Google TV 且系统 8.0 以上——三星 Tizen、LG webOS、海信 VIDAA 不是安卓系统，直接劝退。

1. 手机装 GenTV Remote（gentv.me 或 GitHub Releases 下 `gentv-mobile-*.apk`，手机需 Android 8+）。
2. 电视开调试：设置 → 关于 → 连点「Android TV OS 版本」7 次打开开发者选项，开启 USB 调试；Android 11+ 若只有「无线调试」，用配对码配对。
3. 手机配对：App 里选中电视，在电视上确认调试弹窗（授权选「始终允许本机」），点「安装 GenTV 桌面」。
4. 先验证再设默认：确认遥控器能在桌面正常移动，再点「把 GenTV 设为我的桌面」——它会记录原桌面、保留原厂桌面并校验 Home 键。想先试不切换，就点「只预览」。

不想装手机 App 还有两条路：电脑 + AI 助手（把 README 里的请求复制给 Claude Code / Codex，授权弹窗自己确认），或 U 盘装电视版 APK。U 盘路线不含手机清理和 DNS 过滤。

**踩坑预判**：别手动停用原厂桌面，部分电视会因此开机黑屏，只能靠 ADB 救回来——交接交给工具按记录来做。开机广告也治不了，那是固件在桌面启动前播的，GenTV 清的是桌面本身的广告位。维护完记得关掉 ADB 调试。

## 💭 我的判断

它不是又一个「去广告神器」，真正有意思的是把换桌面、清预装、手机遥控三件事收进一套系统，而且每次改动都记着、能还原——退路写得明明白白。更新日志也诚实得罕见，没验证的就写「待实机验证」。

不过它还很新（89 星、开源不足一月），固件差异大，桌面接管、HDMI、恢复这些得靠实机确认。iPhone 用户目前只能走电脑或 U 盘路线。动手前先去 README 的机型表核一下自己的电视，改之前备份、一次只改几个。
