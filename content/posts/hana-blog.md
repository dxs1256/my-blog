最近发现了一个挺有意思的桌面 AI Agent——**HanaAgent**，GitHub 上 5.6k Star，作者本职是个文员，做这个项目是为了让不会敲命令的人也能用上 AI Agent。

项目地址：https://github.com/liliMozi/openhanako

用下来感觉确实不一样，产品做得很细腻，有温度，分享一下。

## 🧠 它记得住你聊过的事

用大模型的人都知道，新开个窗口它就不认识你了。HanaAgent 自己做了套记忆系统，聊过的事会存下来，下次接着聊。近期的事情记得牢，远期记忆还在优化中。

## 🎭 每个助手能有自己的脾气

有人格模板，也可以自己写人格文件，捏一个说话方式、做事风格都不一样的助手。底层一个 Agent 就是一个文件夹，人格和记忆都在里面，备份就是复制文件夹，没整那些花活。

![HanaAgent 主界面与人格设置](https://i.ibb.co/ksjvyjmn/409839002f3a.png)

## 🔧 能动手干活，不只是聊天

读写电脑上的文件、执行命令、开浏览器查资料、截图、长网页分段截取，这些都会。办公里那些查信息、整理文档的杂活，能交给它干。

## 📋 书桌这个设计很巧妙

每个 Agent 有一张自己的**书桌**，把文件拖上去，再写一张**笺**（便签），告诉它这些文件怎么处理。它会主动去读这张条子，照着做，不用守在聊天窗口等回复。

平时它还会定期巡检书桌，看文件有没有变动。挂个 Cron 定时任务也行，到点自己跑，轻量提醒直接弹通知，重活在后台做完再汇报。

![书桌与笺功能](https://i.ibb.co/ZRBQV37T/52047c5c67cf.png)

## 👥 多助手协作，互相派活

每个 Agent 的记忆、人格、定时任务都独立，互不串扰。它们之间还能拉频道群聊，互相派活——一个管资料，一个管写作，分工随意。

## 📱 聊天软件里也能喊它

同一个 Agent 可以同时接飞书、QQ 等聊天软件，人在外面用手机发句话，它能远程操作家里电脑。不过个人微信挂机器人有封号风险，建议优先选飞书这种官方开放接口的。

![多助手与聊天软件集成](https://i.ibb.co/M5BN26Pj/0bb479ba3084.png)

## 🔒 安全没糊弄

做了两层隔离：读取系统文件没问题，写入和删除都限制在它自己的工作目录里，权限级别在设置里能调。肯在权限上花力气，说明作者打算让人长期用，不是做个演示。

## 🧩 自己学新技能

兼容社区 SKILLS 生态，干活前会自己去 GitHub 装社区技能，也能自己写新技能，默认有一层审核。插件是拖拽安装，很方便。

## ⚙️ 安装配置

macOS 直接下 dmg（已签名公证），Windows 和 Linux 都有安装包。第一次启动有引导，选语言、填名字，然后接模型。

模型要填三个槽位：主对话、轻量工具模型、记忆整理模型。想省钱三个填同一个也能跑。接口选 OpenAI 兼容，填国内厂商的 Key 和地址，或者装 Ollama 跑本地模型。

![安装引导与模型配置](https://i.ibb.co/270JG5h1/737ad3e6d795.png)

## 💡 我的看法

操作简单，产品做得细腻有温度。书桌、笺、定时任务这些设计，一看就是在办公室坐过班的人做的，知道活是怎么一件一件堆起来的。

不过这是个人项目，Issues 有 800 多条，很多还没解决，社区力量还不强。但这么多人反馈，也说明实际使用的人真不少。值得玩玩。
