我电脑的 C 盘常年飘红，系统自带的清理只能删点临时文件，根本挖不出深层的垃圾。之前试过几个商业清理软件，要么功能阉割逼你买会员，要么动不动弹窗推广告，实在烦人。

后来在 GitHub 上逛到一个叫 **MangoDisk** 的项目（⭐2.4k），把磁盘清理、空间树状图和重复文件去重全做进了一个纯本地工具里。用 Rust 从零写的，支持 Windows 和 macOS，前端走 Tauri 2，体积小、不吃内存。我扫了一遍用了大半年的老电脑，几秒钟出结果，一口气挖出快 40G 垃圾——Docker 废弃镜像层、node_modules、早忘了的大模型分块全在里面。清完之后 C 盘直接变蓝了。

项目地址：https://github.com/harry0703/MangoDisk

## 🎯 这是什么

MangoDisk 是开发者 harry0703 个人维护的开源磁盘管理工具，GPL-3.0 协议，全部功能免费无广告。底层用 Rust 写，几百个 G 的硬盘几秒钟就能遍历完，Windows 和 macOS 都有独立客户端，后台挂着基本没感觉。所有扫描都走本地只读，不需要联网上传任何东西，对系统文件的安全性很有保障。

![MangoDisk 完整主界面，布局直观，支持深色和浅色模式](https://i.ibb.co/S46R516k/cddcc8823573.jpg)

项目还处于初级阶段，功能不算完美，但日常磁盘管理该有的基本都齐了。

## ✅ 深度清理

找清理工具最关心的就是能不能把深层垃圾挖干净。我直接点了一次全盘扫描，系统临时文件、崩溃诊断包、浏览器堆积的网页缓存全给找出来了。平时写代码折腾容器，Docker 留在后台的废弃镜像层、前端项目里沉重的 node_modules，它也能识别出来。之前测试本地大模型下载的几个分块文件，自己早就忘了放哪，结果一扫发现光这块就占了 14G。

![深度清理面板，按类别汇总预计释放空间，勾选方便](https://i.ibb.co/ds82fWG1/de411df54ba7.jpg)

有个设计很人性化：面对一长串复杂的英文路径，很多人不敢随便点删除，作者给每个条目配了 AI 解读按钮，点一下就用大白话解释这个目录是哪个软件留下的、平时干嘛用的、删掉会不会影响运行。拿不准的东西看一眼解释心里就有数，不用自己上网一个个查。

## ✅ 磁盘空间分析

除了清垃圾，空间树状图是我觉得最实用的功能。C 盘爆满的时候，光看系统自带的资源管理器根本看不出到底是哪些大件在占地方。

扫完之后整块硬盘按体积大小切成不同颜色的方块，哪个色块面积大，哪个就是吃空间的大户。关键是可以直接往下钻，我顺着最大的色块一路点进 Users 文件夹，再点进软件缓存目录，两三下就揪出了一个几十 G 的陈年安装包，不用在文件夹属性里一个个右键去翻。

![矩形树图展示，色块大小对应文件体积，支持层级下钻](https://i.ibb.co/7B5pK7X/9f38b935828a.jpg)

## ✅ 大文件与重复文件清理

找大文件可以直接拖滑块设大小阈值，比如专门筛选超过 100M 或超过 1G 的文件。我拉了个 500M 的阈值试了下，以前下载完扔在角落忘删的安装包和旧视频，全给找齐按大小排好队了。

![大文件清理列表，按文件大小一目了然排序](https://i.ibb.co/vCSPcrmn/ff8a0ffd5393.jpg)

重复文件这块做得很扎实，比对的是文件底层的内容哈希，不是只看名字。我微信里存过一张照片、手机备份又导过一份，文件名完全不同，它一比对就准确认出来是同一份内容。清理时默认会留下一份原件，不用担心手滑误删母版。

![重复文件比对，精准识别相同内容，默认安全保留一份](https://i.ibb.co/Kj1CHvyB/103b324946a8.jpg)

## ✅ 应用彻底卸载与系统维护

卸载软件最怕有残留。系统自带的卸载往往只删主程序，用户目录和注册表里还留着一堆垃圾配置。MangoDisk 的卸载功能会顺着软件名字把相关配置和缓存一并挖出来删掉，卸得比较干净。

![应用卸载面板，连同关联残留数据一并清理](https://i.ibb.co/MksvCw6J/cd0125b872a8.jpg)

另外还附带了几个实用维护工具：桌面图标变成空白白块、系统搜索卡死、网络有小故障，在系统维护里点一下对应按钮就能自动修复，不需要自己敲复杂的注册表命令。

![系统优化页面，各项功能都有明确开关和说明](https://i.ibb.co/93CcCYD2/e7fe1d5a89f7.jpg)

## 🚀 快速开始

最省心的是去 GitHub Releases 下载安装包，下载就能跑，连配置都不需要：

- Windows 下载 exe 直接运行，macOS 下载 dmg 拖进应用程序文件夹
- 支持 64 位 Windows 10/11，以及 macOS 12.5 以上版本

习惯用终端的也有单行命令安装方式：

```powershell
# Windows PowerShell
irm "https://get.mangodisk.app" | iex
```

```bash
# macOS Homebrew
brew install --cask harry0703/tap/mangodisk
```

应用还带一个独立的 CLI 命令行版本，适合服务器或无头环境。日常清理常用这几条命令：

```bash
# 只做扫描看结果，不删改任何东西
mangodisk clean

# 直接应用推荐的安全项执行清理
mangodisk clean --apply

# 演练一遍看能清多少空间，不真正删除
mangodisk clean --apply --selection all --dry-run
```

## 🎯 我的看法

用了几天，整体感觉不错。市面上很多号称清理的工具，要么功能阉割严重逼着买会员，要么夹带各种广告弹窗。MangoDisk 能在轻量小体积的前提下，把深度清理、空间树图分析和重复文件去重做得这么齐整，确实难得，基本满足日常磁盘管理的大多数需求。

缺点也有：项目还在活跃开发阶段，对国内部分小众软件的残留规则还在补充中。如果是公司里干活的生产电脑，有些重要的项目缓存或配置文件，删之前最好看一眼，别脑子一热全选删除。另外 Windows 上部分系统保护目录，建议右键以管理员身份运行才能扫干净。

作为日常清理系统缓存、找大文件和重复文件的工具，它已经足够好用了——全功能开源免费、干净无广告，C 盘告急的话值得扫一遍。
