我之前写过一篇国产手机去广告，用的是这个工具的早期版本。一个月过去它变了大样：Star 从 433 涨到 8980，版本跳到 0.4.5，最关键的是新增了一个**不连电脑的手机版 App**——以前必须插线开 USB 调试，现在装个 APK、连个 Wi-Fi 就能自己跑完。给长辈手机做净机这件事，门槛又降了一截。

更让我想再推荐一次的是它的实测数据变实了：README 里 60 多款机型的脚本，每一行后面都挂着真机跑通的日期、用时和回读确认数。比如 OPPO Find X9 Pro 九段逐项实测、回读确认 165 项、60 个营销渠道全部关闭 0 遗留；一加 16 九段全跑 397 秒、二次重跑幂等。不是"支持 XX 机型"这种空话，是"这台机 11 月 7 日跑过、几秒一段、关了几个"。

**android-ad-cleaner**（⭐8980）

项目地址：https://github.com/rddmwmddr/android-ad-cleaner

## 🎯 它到底动了什么，没动什么

先说边界，这是它和"卸载派"方案的分水岭。它只拨系统和 App 自带的开关，全程不卸载、不停用系统应用，不改 system 分区。真要动广告组件（像 `com.opos.ads`、`com.miui.systemAdSolution` 这种），用的是 `pm suspend` 挂起——等于把包冻结在系统里，机主点头才执行，一条命令随时解冻。

说简单点：它干的事，全是你手动进设置也能干的，只是替你把这几十个藏在各处的开关一次性找齐、批量关掉。所以系统更新、保修不受影响，最重的动作也只是"冻结"而不是"删除"，想反悔随时还原。

处理范围按来源分五类：

| 类别 | 例子 | 怎么处理 |
|---|---|---|
| 系统广告 | 个性化广告、广告跟踪 OAID | 系统设置开关 |
| 热搜资讯 | 下拉搜索热榜、负一屏资讯、浏览器信息流 | 各 App 开关，浏览器切简洁首页 |
| 推广位 | 商店轮播、开屏、签到福利 | 商店「服务管理」开关 |
| 营销推送 | App 的「内容与营销」通知 | 按渠道关，订单快递保留 |
| 广告组件 / 快应用 | com.opos.ads、点一下就跳的免安装小程序 | pm suspend 挂起 / quickapp off |

## 📣 营销通知按渠道关，不搞一锅端

这是我最认可的设计。多数工具对通知要么全关要么全留，这里的粒度是"渠道"：同一个天气 App，「内容与营销」关掉，「天气预警」保留；购物 App 的活动推送关掉，订单、快递、更新通知照常。

实测下来各机型可关的渠道数差很多——荣耀 PNM-AN10 有 26 个，OPPO Find N5 有 42 个，Find X9 Pro 多达 60 个。执行前会先扫一遍列出候选，服务类默认不勾，避免误伤。

## 🛠 五种用法：从"AI 替我跑"到"手机自己跑"

同一个工具库，按折腾程度铺了五条路——这是它比纯脚本方案友好得多的地方：

| 用法 | 适合谁 | 要准备什么 |
|---|---|---|
| 一：AI 智能体替你跑 | 有电脑想省事 | 电脑、数据线、能执行命令的 AI 工具 |
| 二：聊天 AI 带你点 | 只有手机 | DeepSeek、豆包、ChatGPT 任意一个 |
| 三：照清单手动关 | 想自己掌握每一步 | 只要手机 |
| 四：桌面客户端 | 不想敲命令 | Mac 或 Windows 10/11、数据线 |
| 五：手机版 App | 不想连电脑 | 安卓 11+、Wi-Fi（本次更新新增） |

## 🆕 这次更新真正值得升级的点

0.4.5 这版修的几个问题挺关键。华为上以前会出现"只关营销通知"却把整个 App 通知关掉的误伤，这版把引擎里关通知渠道的那一层重写成先判断、再统一动手，逻辑更稳。手机版也认得 Sui 了，装了 Sui 不用再配对无线调试。

另外几条值得留意：

- **应用内更新**：0.4.2 起客户端能自己检查、下载、安装更新，手机版仍需在系统弹窗确认。0.4.1 及以前没有这功能，得先手动装一次 0.4.2。
- **Mac 签名公证**：Apple 芯片和 Intel 芯片的 dmg 都已签名、过了苹果公证，双击就能打开，不用再跟 Gatekeeper 斗。
- **鸿蒙接入**：0.4.2 起 Mac / Windows 客户端能连纯血鸿蒙手机，不过这条通道官方说明还没在鸿蒙真机上复测，先当尝鲜。
- **国内下载**：Gitee 有镜像，不用登录就能下（Windows 安装版只在 GitHub）。

## 📱 机型覆盖：脚本按型号存，版本对不上会跳过

它按"机型脚本"工作——一台机型的自动操作步骤，记着打开哪个 App、点哪几个字、关哪几个开关。设置页因型号和系统版本而不同，所以每份脚本都绑定具体型号 + 系统版本，版本对不上时引擎会提示，找不到入口的步骤直接跳过，不会乱点。

目前真机跑通覆盖魅族、华为、荣耀、一加、OPPO、小米、Redmi、vivo / iQOO、realme、三星，横跨 ColorOS、HyperOS、OriginOS、MagicOS、Flyme 各大定制系统。不在表里的机型，文档里有教程教你自己写一份脚本提 PR。

一个提醒：同一品牌不同系统小版本，设置页的名字和层级会变，所以别看别人跑通了就以为通用——它强就强在"只认登记过的型号 + 版本"，这份较真恰恰是安全边界的来源。

## 🤔 用了一个月的判断

给长辈手机净机这件事，现在的最优解我已经不用纠结了——直接用手机版 App，不用碰电脑，不用开 USB 调试，装上授权后连 Wi-Fi 自己跑完，做完提醒关开发者模式。它不是最激进的去广告方案（想彻底精简，卸载派依然更狠），但它把风险上限压到了最低：全部可还原，最重动作是挂起而非删除，营销通知还按渠道精挑细选地关。如果你上次按我那篇旧文用过 0.2.x，这版值得重新下一次——手机版和渠道引擎的改进是实打实的。
