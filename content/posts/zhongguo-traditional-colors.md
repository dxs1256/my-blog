**中华传统色**（⭐1.2k）

项目地址：<https://github.com/nevertoday/zhongguo-traditional-colors>

最近在折腾博客的配色，满脑子都是"这个颜色对不对"、"古代管这个色叫什么"。翻了大半天，发现网上关于传统色的资料要么是零散的色块图，要么只有名称没有色值，真要用起来还得自己一个个去对。

作者 小小东 做了这件事——把 742 种中华传统色全部整理成高清色卡，配了一个功能完整的在线工具箱。

## 🎨 742 张色卡，每张都带完整信息

从"乳白"到"深绿"，每一张色卡都标注了名称、HEX、RGB、CMYK。颜色按编号排列，可以按名称、色号、HEX 搜索，也能直接按色相浏览。支持下载原图，存到本地做色卡库。

![中华传统色主页](https://i.ibb.co/5hhdznwW/browser-screenshot-03f13f52.png)

## 🔬 实景试色：放进去看效果

选一种颜色，在网页、幻灯片、封面、海报、品牌板五个场景里预览。每个场景都把颜色分配到背景、标题、正文、按钮、强调色五个角色，一眼看出这个颜色在实际布局里好不好看。

![实景试色工作台](https://i.ibb.co/cKM5q0rn/browser-screenshot-69a6fb3e.png)

## 🎯 配色方案生成器

锁定一种颜色当锚点，自动生成五色方案。支持锁定、替换、旋转、导出，也能一键收藏。配色还不满意？还有 8,904 种预置配色方案可以翻——同色、邻近、互补、三角、冷暖、明暗、灰调、中性，涵盖所有常见配色关系。

![配色方案生成器](https://i.ibb.co/JWXG86cW/browser-screenshot-dbe642f2.png)

## ⚡ 硬核工具：几个我没想到的

- **Theme Forge**：把一种传统色直接映射成完整的 shadcn 语义主题（亮色/暗色都有），输出 globals.css，前端开发拿来就能用
- **Terminal 配色**：从传统色生成 16 色 ANSI 终端配色方案，直接复制 Ghostty、Alacritty、kitty 的配置文件
- **渐变逻辑卡**：每种颜色变成浅色、锚点、邻近、深色、双色、渐变路径六张卡
- **使用卡片**：背景/文字双色卡，带对比度检查，适合做 PPT 配色参考
- **本地收藏**：颜色卡、配色方案、使用卡片都能收藏，按类型筛选

## 🧠 10 个 Claude Code 技能

项目还附带了 10 个可独立使用的 Claude Code 技能（`xxd-*` 文件夹），每个都打包了完整的 742 色列表和配色关系数据。从"把模糊的需求转成色值约束"到"品牌色系统搭建"，覆盖了从设计到开发的全链路。

## 怎么用

项目是纯静态站点，线上直接访问 [colors.xiaoxiaodong.ai](https://colors.xiaoxiaodong.ai/) 就能用。如果想本地跑，`npm run manifest && npm run start` 启动开发服务器。完整色卡图片压缩包约 998 MB，通过 GitHub Releases 分发，不占用仓库体积。

作者说这是个开源参考项目，不同屏幕和印刷工艺下颜色会有差异，生产环境用之前建议先实样验证。项目 MIT 协议，自由使用。

我把自己博客的配色方案用 Theme Forge 试了一遍，从 742 张色卡里挑了三组，导出的 globals.css 直接替换就能用，前后不到十分钟。如果你也经常被配色卡住，从这 742 张里找灵感比从头调色快得多。
