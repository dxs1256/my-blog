我家的电视是小米的，平时最烦的不是画质，是那个桌面：第一屏永远塞满热播剧推荐、会员和限免角标，遥控器一开电视先看广告片头。试过关掉各种推荐开关，系统更新后又会给你塞回来；也想过刷机，保修和更新直接打水漂。

后来发现 **Aerial**（⭐4.8k），思路跟清理工具完全不同——它不卸载任何东西，直接把桌面整个换掉：参照 Apple TV 做的 Android TV 桌面，没有广告、没有推荐流，就三样东西：你的 App、壁纸、航拍屏保。

项目地址：https://github.com/pengchujin/aerial-tv

![小米自带桌面 vs 换上 Aerial 之后：左边满屏剧集推荐和限免角标，右边是干净的图标网格](https://i.ibb.co/HLJyy3mG/097f477ccc11.jpg)

## 🎯 自带桌面就是广告位，清开关不如换桌面

国产电视的自带桌面基本都是厂商的广告位：热播剧推荐、会员开通、限免角标，开机还有固件播的片头广告。去广告工具的做法是拆掉系统组件，清是清干净了，但系统更新、保修受影响，手一抖还可能出问题。

Aerial 走的是另一条路：**桌面层替换**。它不动任何系统应用，小米影视、PatchWall 这些还在 App 列表里，小爱同学、小米账号、有线电视照常能用。要还原就一条命令，随时回去。

## 🏠 首页：玻璃底板放常用 App，往下全是你的应用

Aerial 的界面参照 tvOS：常用的一排 App 放在屏幕下方的玻璃底板上，往下滚动是全部应用。有意思的是，小米「应用中心」「米家」这类藏在系统里平时见不到的 App 也会出现——自己家的桌面反而看不到自己家的应用。

![Aerial 首页：下方玻璃底板放常用 App，上方干净无推荐](https://i.ibb.co/fzfpFXNX/64a6192b5f20.jpg)

长按 OK 键（或按菜单键）可以移动、放进文件夹、隐藏、卸载；固定到主屏幕的 HDMI 信号源可以选接的是 Apple TV、PlayStation、Switch、Xbox 还是电脑，自动换成对应图标，还能在手机上起名字。

## 📱 用手机整理：扫码后拖拽排序、改名换图标

用遥控器挪图标有多痛苦，用过的都知道。Aerial 的解法：扫电视上的二维码，手机端就是和电视一模一样的图标网格——按住拖动排序，点一下改名、换图标、放进文件夹或隐藏，还能把 HDMI 信号源加到主屏幕。

![手机整理界面：扫电视二维码后，手机上出现同样的图标网格](https://i.ibb.co/TV1w38x/239dffc1d5f6.jpg)

第一排按上键还能进控制中心：信号源、网络、设置、音量、亮度、个性化，一个面板全搞定。壁纸用必应每日精选、14 张内置壁纸，或停在主屏幕 10 秒后航拍在磁贴后面播放，按任意键停在当前画面。

## 🎬 屏保：Apple TV 的 114 段航拍影片

Aerial 内置 Apple TV 的 114 段航拍影片当屏保，电视支持时播 4K 或 4K 杜比视界；也能换成照片、时钟，或从手机扫码传本地视频。

## 🚀 安装：不 root 不刷机，一条命令还原

装它不需要 root、不刷机、不动系统应用，随时能还原。电脑和电视连同一个网络，先打开电视的 ADB（各品牌入口 README 列得很细：小米在「设置 → 账号与安全」，TCL 是遥控器「上下左右」彩蛋），然后一行命令：

```bash
curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash
```

**踩坑预判**：小米电视待机后会关掉 ADB，所以上面加了 `KEEP_ADB=1`，Aerial 会重新打开，方便以后升级——不加的话下次升级还得再手动开一次。老电视或内存小的电视可能会卡，1.48 起会自动改用「流畅」效果（面板纯色、去掉高光），也能在个性化里手动选。

它怎么做到开机自动接管的？国产电视大多只认自家桌面，待机时还会清理第三方 App。Aerial 用一个无障碍服务盯着窗口变化（只看哪个窗口在前台，不读屏幕内容），原桌面一出现就切回来；被清理后再靠通知监听让系统把它拉起来（同样不读通知）。原生 Android TV 上不需要这些，直接设成默认桌面就行。升级也省心：1.32 起控制中心会出现「有新版本」，电视自己的安装界面确认即可，设置都保留。

## 💭 我的判断

Aerial 不是又一个「去广告神器」，它解决的是更深一层的问题：国产电视的自带桌面本身就是广告位，开关越关越多，Aerial 直接把「桌面」这个入口换成干净的。项目 2026-10-20 创建，五天冲到 4.8k star，版本迭代很勤。实测适配覆盖小米、TCL、创维、索尼等一票国产电视，盒子和投影仪也能装；LG webOS、三星 Tizen、华为鸿蒙不支持，打不开 ADB 的老机型（极米 H3、老乐视、荣耀智慧屏）暂时也装不了。想少折腾的，先看 README 的机型表再动手。
