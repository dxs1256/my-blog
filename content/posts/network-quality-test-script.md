买 VPS 或者换机房后，最烦的就是测网络质量。以前要一个个手动跑：回程路由、BGP 信息、三网延迟、测速……每个脚本都不一样，特别麻烦。

最近发现了一个网络质量检测脚本，一行命令全部搞定。

## 怎么用

直接终端跑：

```
bash <(curl -sL http://Net.Check.Place)
```

也可以交互界面操作，排版更清晰：

```
bash <(curl -Ls http://Check.Place) -N
```

中英文双语支持，IPv4/IPv6 双栈都能查，跑完的结果排版精美，多终端单屏优化，方便截图分享。

![网络质量检测脚本运行界面](https://i.ibb.co/Mk45HQdk/d54a27bb5062.jpg)

## 七大测试模块

这个脚本一次性覆盖了七项测试，每项都是刚需：

1. **BGP 信息** — 完整 AS 号、IP 段、运营商信息
2. **本地策略** — 本地路由策略和接入信息
3. **接入信息** — 上游接入点、带宽等
4. **三网 TCP 大包延迟** — 电信/联通/移动 TCP 大包延迟测试
5. **三网回程路由** — 31 个省/市/自治区回程延迟，一目了然
6. **国内测速** — 基于 Speedtest 的中国大陆（含大湾区）三网网速测试
7. **国际互连** — 全球五大洲网速及延迟测试

基础数据源自 BGP.TOOLS 和 BGP.HE.NET 数据库，上游及接入信息会直观展示中国大陆地区 31 个省/市/自治区电信/联通/移动三网回程延迟。

![脚本测试结果展示](https://i.ibb.co/66XZRjr/4e497a8d2aca.png)

## 其他实用功能

还支持几种灵活的测试模式：

- **延迟模式**：只测延迟，省流量
- **低数据模式**：用小数据包测试，适合移动网络
- **跳过任意章节**：不想测的部分直接跳过
- **JSON 输出**：跑完的数据可以导出 JSON，方便自己写脚本做数据分析

## 适合谁用

- **买 VPS 前**：先跑一下脚本，看看回程路由和延迟，判断网络质量
- **换机房后**：一键确认线路是否正常
- **网络对比**：两台机器各跑一次，结果一目了然
- **运维排查**：快速定位网络问题出在哪一环节
